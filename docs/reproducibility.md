**Source.** Women's E-Commerce Clothing Reviews, Kaggle (<https://www.kaggle.com/datasets/nicapotato/womens-ecommerce-clothing-reviews>), public. The data is not committed. Download the CSV to `data/raw/reviews.csv`.

**Integrity of the file used.** `data/raw/reviews.csv` has 23,486 rows and 11 columns. SHA-256: `bd93cc515747ad1f87b8bc863c9e40da758509e6db6506a96d06976e61e36ee0`. ## 7. Preprocessing

`src/features/preprocessing.py`, applied once to produce the `Review Text Clean` column:

1. Lowercase; remove URLs, HTML tags and digits; remove punctuation; collapse whitespace.
2. NLTK `word_tokenize`.
3. POS tags (`averaged_perceptron_tagger`) drive WordNet lemmatization.
4. Remove NLTK English stopwords.

Which model sees which text:

| Model | Input column |
|---|---|
| TF-IDF + logistic regression | `Review Text Clean` |
| LDA | `Review Text Clean` (tokenized) |
| DistilBERT | `Review Text`, raw, as written |
| BERTopic (embeddings) | `Review Text`, raw |

## 8. Hyperparameters

**TF-IDF + logistic regression (baseline).** `TfidfVectorizer`: 20,000 features, 1-2 grams, `min_df` 2, `max_df` 0.9, `sublinear_tf`, no lowercasing. `LogisticRegression`: `max_iter` 1000, `class_weight="balanced"`, seed 42. Runs in seconds on the CPU.

**DistilBERT.** `distilbert-base-uncased`, `max_length` 256, learning rate 2e-5, batch size 16 (eval batch 32), 3 epochs, weight decay 0.01, 500 warmup steps, fp16, evaluation and checkpoint each epoch, the best checkpoint by validation macro-F1 kept (`load_best_model_at_end`), `save_total_limit` 1, seed 42. Loss is cross-entropy with inverse-frequency class weights normalized to mean 1 (`class_weights`, mirroring the baseline's balanced weights). Trained with `src.models.transformer.train_transformer`, as in `notebooks/02_distilbert_colab.ipynb`.

**LDA.** gensim `LdaModel`, 10 topics, 10 passes, seed 42. Dictionary filtered to terms in at least 5 documents and at most 50% of them.

**BERTopic (primary).** `all-MiniLM-L6-v2` embeddings (batch size 64) of raw text; UMAP `n_neighbors` 15, `n_components` 5, `min_dist` 0.0, cosine metric, seed 42; HDBSCAN through BERTopic with `min_topic_size` 25 and no topic-count cap; `CountVectorizer` with English stopwords for the c-TF-IDF topic words; no topic probabilities. Result: 53 topics, 32.3% of reviews unassigned.

**Topic merge.** Complete-linkage clustering of c-TF-IDF cosine similarity, merging groups whose every pair is at least 0.45 similar, never merging topics above 500 reviews. 53 to 45 topics. Run with `python -m scripts.topic_merge`.

**Coherence.** `c_v` over one shared tokenized corpus and dictionary for every model compared.

**Metrics.** Accuracy, macro-F1 (the headline metric, since about 77% of reviews are positive), weighted-F1, per-class precision/recall/F1, confusion matrix (`src/evaluation/metrics.py`).

## 10. Known limits on exact reproducibility

- **DistilBERT is not bit-reproducible on a GPU**, even with a fixed seed. Two runs with identical settings gave 586 validation errors (accuracy 0.8285, macro-F1 0.676) and 580 errors (accuracy 0.8303, macro-F1 0.6823). A reader re-running the notebook should expect macro-F1 within about 0.006 of the reported value, not the same digits. No other source of variation is known; the seed, data and settings were the same.
- **The reported run's weights were not retained.** The 580-error run was trained in a Colab session whose runtime was reset before the model could be reloaded, and no copy was found on Drive or locally. What is retained is its validation predictions (`reports/val_preds_distilbert.csv`), from which every DistilBERT number in the results draft can be re-derived. The retained predictions were checked against the notebook's recorded metrics (accuracy 0.8303, macro-F1 0.6823, 580 errors).
- **The test set has not been evaluated** by either sentiment model. The planned single evaluation of both models moves to the final report, and for that run the weights and test predictions will be saved in the same session as training. See `docs/results-draft.md`, section 1.2.
- **Two environments.** DistilBERT ran on Colab with torch 2.11.0+cu128; everything else ran locally with torch 2.14.0. Neither affects the baseline or the topic results.
- **A single stratified split**, with no cross-validation and no confidence intervals.
- **Topic labels** (`reports/topic_labels.csv`) are one reader's judgement, written by hand after reading sample reviews. They are an input file, not something the code derives.
